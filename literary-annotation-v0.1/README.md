# Literary Annotation Dataset v0.1

Chapter-scoped sample: Joseph Conrad, *Heart of Darkness*, Part I (`0000-i`).

## Contents

- Bundle: [`samples/heart_of_darkness_se/sample.json`](samples/heart_of_darkness_se/sample.json)
- Schema: [`schema/literary-annotation.schema.json`](schema/literary-annotation.schema.json)
- Manifest: [`manifest.json`](manifest.json)

## Included layers

- Public-domain chapter text
- Characters, themes, timeline events
- Glossary terms attested in the chapter
- Relationship subgraph
- Theme×chapter scores
